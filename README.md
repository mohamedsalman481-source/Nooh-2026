# نووووووح — برج الأحلام 🎮

لعبة برج لا نهائي بنوح، ابن عزام وإسراء. تتضمن فيديو نوح في الافتتاحية، أنيميشن للشخصية، زخم وقفزات وارتداد من الجدران وكومبو وثلاثة مستويات للصعوبة.

## الرفع على GitHub Pages

1. فك ضغط الملف على جهازك.
2. أنشئ Repository جديدًا على GitHub، مثل `nooooh`.
3. افتح `Add file → Upload files` وارفع **محتويات المجلد**، بما فيها مجلد `assets` كاملًا.
4. تأكد أن `index.html` موجود في جذر المستودع مباشرة، وليس داخل مجلد إضافي. لا ترفع ملف ZIP نفسه.
5. اضغط `Commit changes`.
6. افتح `Settings → Pages`.
7. اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/(root)`، واضغط `Save`.
8. تابع حالة النشر في GitHub؛ رابط اللعبة سيظهر في صفحة Pages.

دليل GitHub الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

اللعبة على GitHub Pages لا تعتمد على تسجيل دخول ChatGPT. إتاحة الرابط تحددها إعدادات الاستضافة في GitHub. الملفات تتضمن فيديو نوح وصوره، وسيكون بإمكان زوار اللعبة مشاهدتها.

## تشغيل محلي

افتح `index.html` في المتصفح. ولتشغيلها من خادم محلي، افتح Terminal في هذا المجلد وشغّل:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

لا يوجد npm أو خطوة بناء أو مفاتيح API. الخط العربي يُحمّل اختياريًا من Google Fonts؛ يوجد خط بديل عند عدم الاتصال.

## التحكم

- الأسهم أو A / D: الحركة.
- مسافة أو سهم لأعلى أو W: القفز. استمرار الضغط لفترة قصيرة يزيد ارتفاع القفزة.
- P أو Escape: إيقاف واستئناف.
- الموبايل: أزرار اليمين واليسار والقفز. لمس ساحة اللعب يقفز أيضًا.
- الأركيد: قفزة واحدة، وارتفاعها يزيد مع سرعة الجري، والصعود يزداد مع الوقت.
- التوربو: حركة وصعود أسرع.
- العائلي: صعود أهدأ وقفزة إضافية في الهواء، مع خيار القفز التلقائي.
- أفضل نتيجة تُحفظ محليًا في المتصفح لكل وضع.

## الملفات

- `index.html`: الواجهة والانترو.
- `style.css`: التنسيق واستجابة الموبايل.
- `game.js`: الحركة والفيزياء والرسم والنقاط والصوت.
- `assets/noah-intro.mp4`: فيديو نوح.
- `assets/noah-intro-poster.jpg`: غلاف الفيديو.
- `assets/noah.png`: صورة البطل.
- `assets/noah-atlas.png`: أطلس أوضاع الحركة.
